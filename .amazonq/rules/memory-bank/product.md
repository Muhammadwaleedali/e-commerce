# E-Commerce Frontend Application

## Project Purpose
A modern React-based e-commerce web application that provides a complete online shopping experience with user authentication, product management, shopping cart functionality, and checkout processes.

## Key Features
- **User Authentication**: Login/register system with JWT token-based authentication
- **Product Catalog**: Browse products by categories with detailed product views
- **Shopping Cart**: Add/remove items, quantity management, persistent cart state
- **Checkout System**: Complete order processing with address management
- **Admin Panel**: Product management, category management, and administrative controls
- **Responsive Design**: Mobile-friendly interface using Tailwind CSS
- **State Management**: Redux Toolkit for global state management
- **API Integration**: Axios-based HTTP client with interceptors for authentication

## Target Users
- **Customers**: End users browsing and purchasing products online
- **Administrators**: Store managers handling product inventory and order management
- **Developers**: Team members maintaining and extending the e-commerce platform

## Value Proposition
Provides a complete, scalable e-commerce solution with modern React architecture, comprehensive state management, and seamless user experience for both customers and administrators.
